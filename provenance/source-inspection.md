# Source-inspection scope

The SI capability map is based on reading implementation paths and their
guards, not on rerunning every CP2K regression input. The following code
families were inspected at the source versions described in this repository:

| Topic | Principal CP2K source files | Interpretation |
| --- | --- | --- |
| Grid construction and symmetry | `kpoint_types.F`, `kpoint_methods.F`, `cryssym.F`, `kpsym.F`, `spglib_f08.F` | Full and reduced meshes, orbit weights and reconstruction data; the Si/Al runs exercise K290, SPGLIB and time reversal at one fixed mesh. |
| Localized-basis transforms and solvers | `kpoint_k_r_trafo_simple.F`, `kpoint_lattice_fft.F`, `qs_kpoint_operators.F` | The table tests compare requested transform modes and selected solver paths, not a universal FFT speedup. |
| K-point exports and analysis | `qs_wannier90.F`, `trexio_utils.F`, `casino_utils.F`, `population_analyses.F` | These are source-level connected capabilities, not numerical results generated by the 18 Si/Al cases. |
| Later DFT+U extension | `dft_plus_u.F` | Loewdin occupations and potentials, force and stress paths on full or time-reversal-reduced meshes; no atomically symmetry-reduced DFT+U validation is claimed. |

The authoritative source and regression inputs are in the public
[CP2K repository](https://github.com/cp2k/cp2k). This inventory records the
reviewed boundary and intentionally does not duplicate upstream code or
unrelated topology-development snapshots.
